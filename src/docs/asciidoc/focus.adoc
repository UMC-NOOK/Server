=== 포커스 종료

`page`는 선택 입력이며, 응답에서 현재 페이지가 없으면 `null`입니다. POST /api/v1/focuses/end는 자정을 넘겨 일별 Focus 행으로 분할 저장되더라도, 종료를 요청한 원본 Focus ID를 기준으로 전체 종료 작업을 하나의 객체로 반환합니다. 응답의 시작 시각, 종료 시각, 집중 시간은 전체 작업의 값이며, 페이지·독서 상태는 작업 완료 후 최종 서재의 값입니다. `totalFocusSec`은 이 사용자가 선택한 책에 대해 누적한 전체 포커스 시간(초)입니다.

=== 포커스 홈 조회

`GET /api/v1/focuses/home`은 선택한 독서 상태의 서재 책 목록과 오늘의 사용자 전체 포커스 시간, 책별 오늘 포커스 시간을 한 번에 조회합니다. 책 목록은 서재 최신 등록순이며 `status`는 필수입니다. `cursor`는 다음 페이지 조회 시 전달하고, `size`의 기본값은 20, 최대값은 100입니다.
