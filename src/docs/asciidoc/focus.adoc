=== 포커스 종료

`POST /api/v1/focuses/end`는 자정을 넘겨 일별 Focus 행으로 분할 저장하더라도, 종료 응답은 원본 Focus ID를 기준으로 하나의 객체로 반환합니다. 시작 시각·종료 시각·집중 시간은 전체 포커스를 기준으로 하며, 페이지·누적 포커스 시간·독서 상태는 처리 후 최종 서재 값을 사용합니다.
