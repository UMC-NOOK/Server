=== 소셜 로그인

`GOOGLE`, `KAKAO` 두 가지 방법으로 소셜 로그인 요청을 보낼 수 있습니다.
인가 코드를 발급받고 code에 담아서 요청을 보내면 됩니다.
 +
탈퇴 유예중(soft delete) 계정이 로그인을 시도하면 `accessToken`/`refreshToken` 대신
`recoveryRequired=true`와 `recoveryToken`(1시간)이 반환됩니다.
사용자가 복구를 확정하면 이 `recoveryToken`으로 `계정 복구` API를 호출합니다.

=== 회원 탈퇴

회원 탈퇴를 요청합니다(soft delete). +
계정은 즉시 비활성화되고 토큰이 무효화되지만, 데이터/사진/소셜 연결은 보존됩니다. +
탈퇴 후 14일 이내 동일 소셜 계정으로 로그인하면 복구할 수 있으며, 유예기간이 지나면 완전 삭제됩니다.
