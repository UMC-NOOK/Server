=== 공통 오류 응답

모든 오류 응답은 `isSuccess`, `code`, `message`, `result` 형식의 `ApiResponse`를 사용합니다.

==== 요청 한도 초과 (429)

요청 횟수 제한에 걸리면 `429 Too Many Requests` 와 `COMMON-006` 을 반환합니다.
거부된 요청은 횟수에 포함되지 않습니다.

- `result.title`, `result.description` 을 공용 팝업의 제목과 본문에 그대로 표시합니다.
- `message` 는 `title + " " + description` 한 줄입니다.
- `Retry-After` 헤더에 다시 시도할 수 있을 때까지 남은 시간(초)을 담습니다.
- 서버 앞단(nginx)의 전체 API 제한에 걸리면 남은 시간을 알 수 없어 `Retry-After` 없이 일반 안내 문구를 반환합니다.
- `result` 가 없는 429(서버가 제어하지 못하는 구간)는 기본 문구 "요청 횟수를 초과했습니다. / 잠시 후 다시 시도해 주세요."를 사용합니다.

[cols="2,3,1,1", options="header"]
|===
| API | 기준 | 한도 | 비고
| `POST /auth/oauth`, `POST /auth/dev/login` | IP | 30회/1분 | 로그인 실패도 집계 (요청 형식 오류(400)는 제외)
| `POST /auth/recover` | IP | 10회/10분 |
| `POST /auth/reissue` | IP | 60회/1분 |
| `GET /books/search/GLOBAL` (cursor 없음 또는 0) | 사용자 | 30회/1분 | `LIBRARY` 검색은 제한 없음
| `GET /books/search/GLOBAL` (cursor > 0) | 사용자 | 60회/1분 |
| `GET /books/{isbn13}` | 사용자 | 60회/1분 |
| `POST /images/upload-url`, `POST /images/upload-urls` | 사용자 | 20장/1분, 100장/일 | 발급 장수 기준, 하루 한도는 KST 자정 초기화. 남은 한도보다 많이 요청하면 전체 거부. 한 번에 최대 5장
| `/api/**` 전체 | IP | 초당 10회 + 순간 100회 | 서버 앞단(nginx). 현재는 기록만 하고 차단하지 않음
|===

[cols="1,1,1", options="header"]
|===
| 상황 | title | description
| 요청 한도 | 요청 한도에 도달했습니다. | `N초 후 다시 시도해 주세요.` (60초 미만) / `N분 후 다시 시도해 주세요.` (60초 이상, 올림)
| 이미지 하루 한도 | 이미지 업로드 한도에 도달했습니다. | 내일 다시 시도해 주세요.
| 서버 앞단(nginx) 제한 | 요청 횟수를 초과했습니다. | 잠시 후 다시 시도해 주세요.
| 외부 도서 정보 초당 한도 (`BOOK_API-003`) | 도서 정보 요청이 너무 많습니다. | `N초 후 다시 시도해 주세요.`
| 외부 도서 정보 하루 한도 (`BOOK_API-003`) | 도서 정보 한도에 도달했습니다. | 내일 다시 시도해 주세요.
|===

외부 도서 정보 한도(`BOOK_API-003`)는 모든 사용자가 함께 쓰는 한도입니다. 외부 호출이 필요한 요청(검색, 처음 조회하는 도서 상세, 직전 목록이 없는 베스트셀러·추천)에서 반환하며, 저장된 도서 상세와 직전 목록이 있는 베스트셀러·추천은 한도가 소진되어도 직전 정보로 제공합니다. 응답 형식은 위와 같습니다(`Retry-After`, `result{title, description}`).
