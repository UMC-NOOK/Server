=== 공통 오류 응답

모든 오류 응답은 `isSuccess`, `code`, `message`, `result` 형식의 `ApiResponse`를 사용합니다.
일반 오류의 `result`는 응답에서 제외되며, 요청값 검증 오류는 필드별 상세 오류 정보를 반환할 수 있습니다.
