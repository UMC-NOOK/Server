=== 독서 기록 목록 조회
독서 기록 목록은 책 단위로 그룹핑되어 반환됩니다.
`order` 로 정렬 기준을 선택할 수 있고,  `emotion` 으로 감정 필터를 적용할 수 있습니다.
`emotion=ALL` 이면 전체 기록을 반환합니다.
첫 요청에서는 `cursor` 를 보내지 않고, 다음 요청부터는 응답의 `nextCursor` 를 전달합니다.

=== 특정 책 기록 감정 필터 조회
특정 책에 남긴 기록을 최신순으로 조회합니다.
`emotion`  을 지정하면 해당 감정 기록만 필터링하고, `ALL` 이면 전체 기록을 반환합니다.
이미지가 연결된 기록은 저장된 key를 기준으로 조회 시점에 presigned GET URL로 변환된 `imgUrls` 로 내려갑니다.
