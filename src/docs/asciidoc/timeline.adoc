=== 독서 이력 요약 조회
독서 이력 요약 조회는 포커스 요약, 기록 요약, 그리고 최신 독서 이력 preview를 함께 반환합니다.
 +
`timelinePreview`는 서버에서 최신 5개의 타임라인 아이템을 기준으로 날짜별 그룹으로 묶어 반환합니다.

요약·전체·상세 조회에서 연결된 포커스 또는 기록이 다른 서재에 속하면 원본이 없는 경우와 동일하게 처리합니다.
타임라인과 저장된 미리보기 문구는 유지하며, 해당 원본의 시간·페이지·본문·감정·이미지는 응답에 사용하지 않습니다.

=== 독서 이력 전체 조회
독서 이력 전체 조회는 서재의 타임라인을 날짜별 그룹으로 반환합니다.
 +
각 그룹은 `year`, `monthDay`, `showYear`와 해당 날짜의 아이템 목록을 포함합니다.

`cursor` 없이 요청하면 첫 페이지를 반환합니다. `size`는 날짜 그룹 수가 아닌 아이템 수이며 기본 20개, 최소 1개, 최대 100개입니다.
발생 시각 내림차순, 같은 시각이면 타임라인 ID 내림차순으로 조회합니다.
응답의 `hasNext`가 true이면 `nextCursor`를 다음 요청의 `cursor`로 그대로 전달합니다.
마지막 페이지 또는 빈 결과는 `hasNext=false`, `nextCursor=null`입니다. 잘못된 커서는 400 응답을 반환합니다.

`showYear`는 연도 표시 여부입니다. 첫 페이지 첫 그룹과 이전 그룹에서 연도가 바뀌는 그룹은 true이며, 같은 연도가 이어지면 페이지가 바뀌어도 false입니다.

같은 날짜의 이력이 여러 페이지에 나뉠 수 있습니다. 이전 페이지의 마지막 그룹과 다음 페이지의 첫 그룹의 `year`, `monthDay`가 같으면 `items`를 합치고 이전 그룹의 `showYear`를 유지합니다.
날짜가 다르면 새 그룹과 해당 그룹의 `showYear`를 그대로 사용합니다.
